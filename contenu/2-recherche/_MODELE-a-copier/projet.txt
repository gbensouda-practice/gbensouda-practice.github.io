# annee    = à droite du titre. Texte libre.
# pipeline = la suite d'étapes affichée dans l'encadré bleu.
#            Sépare les étapes par le signe  >

#            l'encadré disparaît alors complètement.
# tags     = les étiquettes du bas, séparées par des virgules.
#
# operations = ce que tu as fait. Cinq mots possibles, définis dans
#            contenu/vocabulaire.txt : concevoir, systematiser,
#            fabriquer, transmettre, experimenter.
# formes   = dans quoi ça s'incarne. Liste ouverte, même fichier.
