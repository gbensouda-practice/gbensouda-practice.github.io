# ─── ZONE 1 : LA FICHE ─────────────────────────────────────────────
# titre    = ce qui s'affiche en gras. *Un mot entre étoiles* = italique.
# annee    = à droite du titre. Texte libre : 2019, 2022 — 2023, Théâtre…
# rubrique = le sous-titre gris qui regroupe les projets.
#            Réutilise une rubrique existante pour ranger le projet
#            dedans, ou écris-en une nouvelle : elle sera créée.
#            Existantes : Luxe & production
#                         Scénographie & spectacle vivant
# tags     = les petites étiquettes, séparées par des virgules.
#            Elles passent automatiquement en MAJUSCULES.
#
# operations = ce que TU as fait dans ce projet. Cinq mots possibles,
#            pas un de plus, définis dans contenu/vocabulaire.txt :
#              concevoir      définir le principe et la forme
#              systematiser   construire une définition réutilisable
#              fabriquer      produire toi-même la pièce
#              transmettre    produire ce qui permet à d'autres de
#                             faire, et suivre l'exécution
#              experimenter   chercher, prototyper, tester
#            C'est le champ qui dit ta part réelle : « transmettre »
#            sans « fabriquer » veut dire que l'atelier a exécuté.
# formes   = dans quoi ça s'incarne (vitrine, mobilier, sculpture…).
#            Liste ouverte, dans contenu/vocabulaire.txt : si ton
#            projet prend une forme absente, ajoute-la là-bas d'abord.

annee      : 2025

tags       : Rhino, Grasshopper, CNC, Impression 3D

d'étoiles : *comme ceci*.
